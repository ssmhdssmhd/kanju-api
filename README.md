# kanju-api

官解取流接口，PHP 单文件部署。输入官方视频站播放页地址或片名，返回可直接播放的 m3u8 直链；另附 19 个由油猴脚本转换的第三方解析接口。

- 当前版本：**v0.0.3**（202611180709）
- 运行环境：PHP 7.4+，需 `curl`、`json` 扩展
- 默认分支：`main`

> 本仓库为公开仓库，`1.php` 顶部含登录账号与密码，任何人均可查看。如不希望公开，请把仓库改为私有，或把 `KJ_ACCOUNT` / `KJ_PASSWORD` 改为环境变量。

## 接口一览

所有文件均位于站点根目录，调用方式与 `1.php` 完全一致，同样经过站点的防火墙 / CDN / WAF 规则。

| 接口 | 说明 |
| --- | --- |
| `/1.php` | 官解取流：播放页地址或片名 → m3u8 直链 |
| `/index.php` | 解析接口聚合索引页，列出全部 19 个接口 |
| `/1118.php` 等 19 个 | 第三方解析接口，`/脚本ID.php?url=...` |

## 快速开始

```http
GET /1.php?url=<播放页地址或片名>[&ep=集数][&line=线路关键字][&cookie=Cookie]
GET /<脚本ID>.php?url=<官方视频页地址>
```

示例：

```bash
# 直接传片名
curl 'https://你的域名/1.php?url=完美世界'

# 传播放页地址（建议 URL 编码）
curl 'https://你的域名/1.php?url=https%3A%2F%2Fm.v.qq.com%2Fx%2Fm%2Fplay%3Fcid%3Dxxx%26vid%3Dxxx'

# 指定集数与线路
curl 'https://你的域名/1.php?url=完美世界&ep=12&line=1080'

# 第三方解析接口
curl 'https://你的域名/1118.php?url=https%3A%2F%2Fv.qq.com%2Fx%2Fcover%2Fxxx.html'
```

### 参数说明

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `url` | 是 | 官方播放页地址，或直接传片名 |
| `ep` | 否 | 指定集数，默认取标题中的集数，取不到按第 1 集 |
| `line` | 否 | 线路关键字，如 `1080`、`官方R`，默认按清晰度优先 |
| `cookie` | 否 | App 会话 Cookie，优先级高于自动登录 |

> 播放页地址建议做 URL 编码，否则其中的 `&vid=` 等参数会被截断。

## 返回格式

业务码放在 body 的 `code` 字段，HTTP 状态码恒为 200，方便播放器直接解析。

成功：

```json
{"code":200,"msg":"success","url":"https://.../index.m3u8","title":"完美世界","ext":"m3u8"}
```

失败：

```json
{"code":400,"msg":"缺少参数 url"}
{"code":401,"msg":"该内容的所有公开线路都需要登录，请把 App 的 Cookie 填入 KJ_COOKIE 或请求带 ?cookie="}
{"code":404,"msg":"未找到匹配影片"}
{"code":502,"msg":"播放页抓取失败，请直接传剧名"}
```

`ext` 取值：

| 值 | 含义 |
| --- | --- |
| `m3u8` | HLS 播放直链 |
| `mp4` / `flv` | 普通视频直链 |
| `player` | 第三方播放器页地址，前端用 iframe 嵌入播放 |

## 部署

1. 把根目录下所有 `*.php` 上传到支持 PHP 的站点根目录（Apache / Nginx + PHP-FPM 均可）。
2. 直接访问 `https://你的域名/1.php?url=...`。
3. 已内置 CORS（`Access-Control-Allow-Origin: *`），前端可跨域调用。
4. 解析接口与 `1.php` 同级，无需额外配置伪静态或放行子目录。

推荐开启 HTTPS；如站点启用了防火墙，请确认 `*.php` 与 `?url=` 查询参数未被拦截。

## 1.php 匹配策略

1. 抓官方播放页标题（`og:title` / `itemprop=name` / `<title>`），清洗站点后缀，拆出片名与集数。
2. 用片名搜索同名资源，按匹配度排序（完全匹配 > 包含匹配，可直接播放的加分）。
3. 逐个资源取对应剧集，再逐条尝试该剧集的所有线路。
4. 某条线路返回 `playback_user_session_required` 时跳过，继续试其他线路和其他同名资源。
5. 全部公开线路都要求登录时，用文件顶部账号自动登录一次并重试，仍失败才提示传 `?cookie=`。
