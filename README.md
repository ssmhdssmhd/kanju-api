# kanju-api

官解取流接口（PHP 单文件）。输入官方视频站播放页地址或片名，返回可直接播放的 m3u8 直链。

- 当前版本：**v0.0.1**
- 运行环境：PHP 7.4+（需 curl、json 扩展）
- 主文件：[`1.php`](1.php)

> 本仓库为私有仓库，脚本内含登录账号，请勿公开或外传。

## 接口

```
GET /1.php?url=<播放页地址或片名>[&ep=集数][&line=线路关键字][&cookie=Cookie]
```

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `url` | 是 | 官方播放页地址（腾讯/爱奇艺/优酷/芒果/B站等），或直接传片名 |
| `ep` | 否 | 指定集数，默认取播放页标题里的集数，取不到按第 1 集 |
| `line` | 否 | 指定线路关键字，如 `1080`、`官方R`，默认按清晰度优先 |
| `cookie` | 否 | 已抓到 App 会话 Cookie 时传入，优先级高于自动登录 |

**建议对播放页地址做 URL 编码**，否则地址里的 `&vid=` 等参数会被截断。

## 返回

成功：

```json
{"code":200,"msg":"success","url":"https://.../index.m3u8","title":"完美世界","ext":"m3u8"}
```

失败：

```json
{"code":404,"msg":"未找到匹配影片"}
{"code":401,"msg":"该内容的所有公开线路都需要登录，请把 App 的 Cookie 填入 KJ_COOKIE 或请求带 ?cookie="}
{"code":502,"msg":"播放页抓取失败，请直接传剧名: /1.php?url=影片名"}
```

业务码放在 body 的 `code` 字段，HTTP 状态码恒为 200，方便播放器直接解析。

## 匹配策略

1. 抓官方播放页标题（`og:title` / `itemprop=name` / `<title>`），清洗站点后缀，拆出片名与集数。
2. 用片名搜索同名资源，按匹配度排序（完全匹配 > 包含匹配，可直接播放的加分）。
3. 逐个资源取对应剧集，再逐条尝试该剧集的所有线路。
4. 某条线路返回 `playback_user_session_required` 时**跳过该线路**，继续试其他线路和其他同名资源；只有全部失败才返回 401。
5. 全部公开线路都要求登录时，用文件顶部账号自动登录一次并重试，仍失败才提示传 `?cookie=`。

## 部署

1. 把 `1.php` 上传到支持 PHP 的站点目录（Apache/Nginx + PHP-FPM 均可）。
2. 直接访问 `https://你的域名/1.php?url=...`。
3. 已内置 CORS（`Access-Control-Allow-Origin: *`），前端可跨域调用。

## 本地验证

```bash
php -S 127.0.0.1:8897 -t .
curl 'http://127.0.0.1:8897/1.php?url=%E6%B3%B0%E5%9D%A6%E5%B0%BC%E5%85%8B%E5%8F%B7'
```

实测结果：

| 输入 | 结果 |
| --- | --- |
| `泰坦尼克号` | 200，第 2 条公开线路返回 m3u8（跟随后 200 `application/vnd.apple.mpegurl`） |
| `完美世界` | 200，m3u8 |
| 腾讯播放页链接 | 200，标题「完美世界」 |
| `千与千寻` | 401，所有公开线路均需登录 |
